📱 PhonePe Pulse Data Visualization and Exploration

A comprehensive data analysis and visualization project built using Python, PostgreSQL, and Streamlit to explore and visualize transaction trends from the PhonePe Pulse GitHub repository.

📌 Project Overview

This project extracts data from the PhonePe Pulse dataset, stores it in a PostgreSQL database, and presents interactive dashboards using Streamlit.

Users can explore:

📈 Transaction Amount and Count
🛡️ Insurance Data
📍 District and Pincode-Level Analysis
📱 Registered Users and App Opens
🗺️ India Choropleth Maps
📊 Year-wise and Quarter-wise Trends

🎯 Objectives
Extract and transform JSON data from the PhonePe Pulse repository
Store cleaned data in PostgreSQL tables
Build SQL queries for analysis
Create interactive visualizations using Plotly
Deploy a user-friendly dashboard with Streamlit

ETL Workflow
